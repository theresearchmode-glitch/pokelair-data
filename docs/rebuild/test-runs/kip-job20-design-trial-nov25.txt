OPTION A — SLANTED TWO-PART LIVE STAMP (.k-reg) [RECOMMENDED]
================================================================================
1. The one creative idea:
   Split the approved sentence ("Day 3 of Reg M-D: 12 events, 840 players so far") at
   the colon into a two-part slanted ticket/stamp: a solid Nasty pink (--k-go) left stub
   in Unbounded slanted ("Day 3 of Reg M-D") joined flush to a crisp 2px-bordered body
   ("12 events, 840 players so far") in Instrument Sans, skewed -8deg with counter-skewed
   inner spans.

2. Why it is NastyPlot and not "any other site" (Rule 11):
   - Directly extends NastyPlot's signature -8deg slanted ticket/slab grammar (the pink
     #1 podium tags on Meta, .k-tag.k-live, .k-kicker, and .k-go buttons).
   - Pairs Unbounded slanted (display stub) with Instrument Sans (data count) using only
     NastyPlot's --k-go pink, --surface / --sd-ink, and --k-on-go tokens.
   - Zero generic AI/SaaS rounded warning pills, zero amber alert boxes, zero icons/emoji.

3. How it meets the hard height limits (numbers):
   - Meta on 390x844 (limit: Pokémon/Tournaments tabs <= 456px from top):
     Instead of stacking above the tabs (where np-dnote already pushes tabs near 460px),
     .k-reg REPLACES the existing "Reg M-C doubles · 13,631 tournament teams" line that
     already sits BELOW the tabs on 390px phones (and beside the [?] button).
     Height added above Pokémon/Tournaments tabs on 390x844: +0px.
     On 1440px desktop, it replaces that same metadata line under the lead (~28px height
     for a ~24px line: +4px net).
   - Home on 390x844 & 390x664 (limit: both start buttons on first screen at 390x844 and
     within 80px at 390x664):
     In the dark hero ledge, .k-reg.k-reg-ink REPLACES the existing "Reg M-D in 7 days."
     (390px) / "Reg M-D is coming..." (1440px) countdown sentence inside the hero copy
     block (28px single-line height replacing 1–2 wrapped lines of countdown text: ~0px
     net change, keeping Score My Team and Build Me a Team in the exact same position).

4. Proposed code change (kit.js + kit.css):
   --- kit.js (new shared helper) ---
   V2.kRegNote = (r, o = {}) => {
     if (!r || !r.reg || !r.day) return '';
     const lead = `Day ${r.day} of Reg ${r.reg}`;
     const tail = `${Number(r.events || 0).toLocaleString('en-US')} events, ${Number(r.players || 0).toLocaleString('en-US')} players so far`;
     const full = `${lead}: ${tail}`;
     return `<p class="k-reg${o.ink ? ' k-reg-ink' : ''}" role="status" aria-label="${V2.esc(full)}"><span class="k-reg-stub"><span>${V2.esc(lead)}</span></span><span class="k-reg-body"><span>${V2.esc(tail)}</span></span></p>`;
   };

   --- kit.css (new rules, tokens.css only) ---
   .k-reg{display:inline-flex;flex-wrap:wrap;align-items:stretch;max-width:100%;margin:0;font-family:var(--b);font-size:var(--t13);line-height:1.5;transform:skewX(-8deg)}
   .k-reg-stub{display:inline-flex;align-items:center;padding:2px var(--s2);background:var(--k-go);color:var(--k-on-go);font-family:var(--u);font-size:var(--t13);font-weight:800;letter-spacing:-.01em;white-space:nowrap}
   .k-reg-stub>span,.k-reg-body>span{transform:skewX(8deg);display:inline-block}
   .k-reg-body{display:inline-flex;align-items:center;padding:2px var(--s3);background:var(--surface);color:var(--ink);border:2px solid var(--k-go);border-left:0;font-weight:600}

OPTION B — AMBER-NOTCHED DATA TAPE (.k-regt)
================================================================================
1. The one creative idea:
   Evolve the existing .np-dnote slanted amber dash (--mid) into a compact inline data-tape
   strip: a -24deg (--slant) amber dash, Unbounded slanted bold "Day 3 of Reg M-D:", and
   Instrument Sans "12 events, 840 players so far" resting on a 2px --mid bottom tick rule
   with a subtle 10% --mid wash.

2. Why it is NastyPlot and not "any other site" (Rule 11):
   - Directly inherits .np-dnote's signature -24deg slanted amber dash (the yellow dash at
     the top of meta-390-light.png), so players immediately recognize it as a data-freshness
     sibling rather than a marketing badge.
   - Uses Unbounded slanted for the regulation stamp and NastyPlot's flat architectural tape
     rules (zero border-radius, crisp bottom accent rule) instead of a rounded warning card.

3. How it meets the hard height limits (numbers):
   - Uses the exact same replacement slots as Option A:
     - Meta 390x844: replaces "Reg M-C doubles · 13,631 tournament teams" below the tabs
       -> +0px above Pokémon/Tournaments tabs (tabs stay <= 456px).
     - Home 390x844 & 390x664: replaces the "Reg M-D in 7 days." countdown inside the dark
       hero ledge -> ~0px net height, keeping both start buttons on the first screen.

WHAT I'M UNSURE ABOUT
================================================================================
1. On 320px–359px narrow phones (e.g., iPhone SE), Option A's two-part stamp ("Day 3 of
   Reg M-D" + "12 events, 840 players so far") wraps onto 2 stacked slanted bars when
   width < ~340px; I'm unsure whether Sim prefers the wrapped two-row stub look or wants
   the border-left restored on the wrapped second line (easily solved with a small
   @media (max-width:359.98px) tweak once tested in a real browser).
2. On Meta 390px, placing the note in the existing "Reg M-C doubles · 13,631 tournament
   teams" slot below the tabs guarantees +0px above the 456px tab limit, but means the
   note sits below the tabs rather than above the H1. If Sim wants it visible *above* the
   tabs on phones, it would have to replace the "META · THE LINE-UP" kicker itself during
   the first 14 days (also +0px height).
3. Singular/plural grammar when day === 1 or events === 1 ("1 event" vs "12 events") was
   not shown in the example sentence; HH/Sim should confirm exact singular phrasing.
