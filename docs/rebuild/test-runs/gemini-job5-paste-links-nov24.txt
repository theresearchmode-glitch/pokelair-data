1. OVERALL VERDICT
mostly solid, with 8 real edge-case bugs (accented names, lowercase natures/abilities, hand-edited team-link stat/move validation, and exportPaste inventing defaults for blank slots) — all fixable with small diffs; zero privacy or XSS leaks found in the 3 files shown.

====================================================================
2. PART A — PER-FUNCTION SUMMARY
====================================================================
app/src/app/19-showdown-paste.js:
- stoneFor(p): accepts roster Pokémon `p`; returns Mega Stone string from META docs -> SETS -> MEGA_STONE -> fallback `p.b + 'ite'`. Can fail if `STONE_RE`/`megaFormFor`/`byName` are missing or a new Mega isn't in META/SETS/MEGA_STONE.
- exportPaste(): no args (reads `members()`, `S.slots`); returns Showdown text. Fills missing `m.item` with `topItems(p).it[0][0]` and missing `m.spread` with `commonSpread(p)`, so re-importing a team with blank item/spread invents defaults the player never chose (Finding #5). Also writes `Ability: undefined` if `ability` is null/undefined.
- okNat0(nat): accepts nature string; returns canonical nature in `NATURES` (mapping Docile/Serious/Bashful/Quirky -> Hardy) or `null`. Case-sensitive (`'jolly'` -> `null`, Finding #2).
- pasteSpread(lines): accepts trimmed line array; returns `{nat, v, ev}` or `{..., over32: true}` or `null`. Handles `\r\n`, tabs, classic EVs > 32 (if total > SP_TOTAL), and `EVs: 0 HP`; ignores `IVs:`/`Level:`/`Shiny: Yes`/`Tera Type:` cleanly. Drops lowercase natures via `okNat0`.
- pasteItemOK(it): accepts item string; returns boolean. Blocks Choice Band/Specs/Assault Vest; checks `itemPool()` + `REGMC_ITEMS` + `CALC_ITEMS` + `extra`. Case-sensitive unless `canonItem` normalizes it (unseen).
- pnorm(s): accepts string; strips non-`[a-z0-9]`. Strips accented chars like `é` instead of NFD-folding (Finding #1).
- pasteSuggest(name): accepts species string; returns closest `ROSTER` display name within edit distance <= 2 (or 3 if len >= 9) if unique. O(1) length-diff guard prevents 100 KB hangs.
- pasteProse(lines): accepts line array; returns true if no Showdown markers and first line has >= 5 words or > 30 chars.
- speciesFromPaste(name): accepts species string; returns `ROSTER` entry via `pnorm(p.n)`, hardcoded `alias`, or `pnorm(p.d)`, else `null`.
- parsePaste(text): accepts raw paste; returns `{slots, notes, over}`. Handles `\r\n`, tabs, empty lines, `Shiny: Yes`, `IVs:`, `Level:`, `Tera Type:`, `(M)`/`(F)`, `>6` Pokémon, duplicates, unknown species/moves/items, and 100 KB pastes without hanging. Bugs: `nameOf` splits on first `' @ '` instead of `lastIndexOf(' @ ')` (Finding #4); `p.a.includes(abl)` is case-sensitive (Finding #3); direct `SP_TOTAL` reference on line 122 throws if `SP_TOTAL` is undefined; non-Mega holding a Mega Stone for another species or unrelated Mega Stone is silently ignored without a note (Finding #9).
- importPaste(raw): accepts raw text/link; returns `{shared}`, `{error}`, or `{msg}`. Calls `decodeTeam` first; mutates `S.slots` via `normSlots`.
- renderPastePanel(): renders `#pastePanel`, escaping `exportPaste()` with `esc()`.
- slotsPaste(slots): temporarily swaps `S.slots`/`S.format`, calls `exportPaste()`, restores in `finally`.
- sdBlock(x), sdSpecies(p), sheetPaste(mons), sdSheetFor(names, player), sdNames(names, player): formats event team sheets into Showdown text; `sheetPaste` NFD-folds `m.nt` and fills missing items/abilities/moves from common sets.

app/src/app/45-team-links.js:
- tlB64(str) / tlUnB64(code): UTF-8 safe URL-safe base64 (`-`/`_`, no padding) encode/decode.
- teamCode() / teamLinkBase() / teamLink(): packs up to `S.slots` (`{v: 1, f: 'doubles', s, n?}`) into base64url; `n` capped at 60 chars.
- decodeTeam(text): accepts full URL, `team=<code>`, or bare code; returns `{f, n, slots}` or `null`. Catches malformed/truncated base64 and rejects `v !== 1`. Bugs: `spOf` accepts any `\w*` nature and out-of-range stat points > 32 or sum > 66 (Finding #6); `r[2]` moves are not validated against `LEARN`/`MV` (Finding #7); standard base64 (`+`/`/`/`=`) is rejected (Finding #8).
- loadShared(x) / applyShared(x) / copyTeamLink(btn) / checkSharedLink(): `checkSharedLink` escapes `x.n` with `esc()` in `bar.innerHTML`; `applyShared` passes `x.n` to unseen `toast()`.
- boxCode() / boxLink() / decodeBox(text) / applyBox(x, mode) / checkBoxLink(): packs/decodes up to 400 box Pokémon (base forms). Same standard-base64 regex limit on line 67.

app/src/app/41-replay-import.js:
- addReplay(text): calls unseen `parseReplay(text)`, pushes `{t, r, b, tm, o}` (max 400) to `S.log`, calls `persist()`, updates `#replayOut.textContent` (XSS-safe).
- renderReplayBox() & listeners: `#replayFile` reads file via `FileReader` and extracts `<script type="text/plain" class="battle-log-data">...</script>`. If HTML attributes are reordered/single-quoted, passes full HTML to `parseReplay` (Finding #10).

6. PRIVACY CHECK
====================================================================
Does any of this code send, log, or keep anything a player typed beyond their own device?
- **No** (checked by reading all 3 files).
- `19-showdown-paste.js`: Zero network calls (`fetch`/`XMLHttpRequest`/`beacon`); pure in-memory parsing and DOM rendering (`renderPastePanel`).
- `45-team-links.js`: Zero network calls. Encodes the user's team/box into a URL hash (`#team=` / `#box=`) only when the user clicks Copy; `checkSharedLink` clears the hash via `history.replaceState` on line 57.
- `41-replay-import.js`: Line 4 states `// Everything runs in the page; nothing is fetched.` Line 9 stores only `{t: Date.now(), r: x.r, b: x.b, tm: members().map(m => m.p.n), o: x.o}` in `S.log` (saved on-device via `persist()`); replay player names `x.me` and `x.them` are shown transiently in `#replayOut.textContent` on line 11 and never saved.

7. ORDER QUESTIONS FOR HH (S1), "I'M UNSURE" (S6) & UNSEEN FILES
====================================================================
Order questions for HH (S1):
1. `exportPaste()` filling blank items/spreads (Finding #5, 19-showdown-paste.js:23,27):
   `exportPaste()` intentionally fills empty `m.item` with `topItems(p)` and empty `m.spread` with `commonSpread(p)` (per `renderPastePanel` line 160: "otherwise the most common ones from real play"), which breaks `paste -> exportPaste -> paste` round-trip fidelity for blank slots.
   - Option (a) Keep as-is (convenient Showdown export, non-lossy for user-set items/spreads).
   - Option (b) Export only `m.item` / `m.spread` when explicitly set so round-trip is exact.

I'm unsure (S6):
- Whether `toast()` and `#pasteNotes` callers escape HTML or use `.textContent` when rendering `{error}` / `{msg}` / `x.n` (so I cannot confirm whether `<script>` in an unknown species name or `x.n` in `applyShared` is safe in the caller).
- Whether `normSlots()` validates `mv` in `decodeTeam()` (Finding #7).
- Whether `parseReplay()` in `41-replay-data.js` handles an unstripped full `.html` replay file safely (Finding #10).
