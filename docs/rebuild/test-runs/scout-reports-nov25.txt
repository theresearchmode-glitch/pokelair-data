WHAT IT DOES (the steps run in this order:
method, origin, size, parse, validate, Turnstile, clean-up, store)
1. Origin check, originAllowed()
   - A different site's Origin gets 403. So do look-alike sites and "null".
   - Sec-Fetch-Site cross-site or same-site gets 403.
   - Allowed: https://nastyplot.org and https://www.nastyplot.org.
     The ALLOWED_ORIGINS variable (a comma list) replaces that list.
   - No Origin at all is allowed by default (Turnstile is still needed),
     so the existing W8 test stays valid.
     REQUIRE_ORIGIN=1 refuses requests with no Origin.
2. Size check, readCapped()
   - 16 KB cap, giving 413 before the JSON is parsed.
   - Checks Content-Length, then the real byte count, which catches a body sent without Content-Length.
   - A non-number Content-Length is refused.
3. Clean-up, scrubContact(), runs just before storing
   - Emails become [email removed]. It catches plain addresses and spelled-out ones:
     at/dot, (at), [at], {at}.
   - Phone numbers become [phone removed]: runs of 10-15 digits with spaces, dashes,
     dots, brackets or a +, and also 555-1234.
   - Kept as typed: 252/4/0, 13,631, 2026-11-25, 6-2, 44.5%, "at Worlds 2025".
